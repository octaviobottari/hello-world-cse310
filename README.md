# Overview

As a software engineer, I am continuously building my foundational skills and portfolio. This project represents my first step in CSE 310, where I am establishing a consistent workflow for creating, documenting, and publishing software. The purpose is to demonstrate my ability to set up a development environment, use Git and GitHub for version control, and create professional documentation including video walkthroughs.

This software is a simple "Hello World" program that prints a greeting message to the console. While minimal, it serves as a template for how I will structure all future modules in this course.

[Software Demo Video](https://www.loom.com/share/9acffdfe3e4b4d5b90c471f0d8f85fa9)

# Development Environment

- **Visual Studio Code** - Primary code editor
- **Git** - Version control system
- **GitHub** - Remote repository hosting
- **Loom** - Screen recording for video demo
- **Terminal/Command Prompt** - Running the program

The software was written in **JavaScript (Node.js)**. I chose JavaScript because it is lightweight, requires no compilation, and runs easily from the terminal using Node.js.
